### Get paid in Africa without a local company.

Itaja is the merchant of record for software sold in Africa: mobile money, cards and wallets, subscriptions, prepaid credits and licence keys, taxes and payouts. You ship the product; Itaja collects, bills and pays you.

[Website](https://getitaja.com) · [Documentation](https://docs.getitaja.com) · [API reference](https://api.getitaja.com/api/references)

> Itaja is in private beta, opening soon. Join the waiting list on [getitaja.com](https://getitaja.com).

#### Build with Itaja

| | |
|---|---|
| **[skills](https://github.com/itaja/skills)** | Agent skills that let a coding agent integrate Itaja into a merchant's app — securely, against the live API. `npx skills add itaja/skills` |
| **[itaja-sdks](https://github.com/itaja/itaja-sdks)** | Official server SDKs: [`@itaja/node`](https://www.npmjs.com/package/@itaja/node) · [`itaja`](https://pypi.org/project/itaja/) for Python · [`itaja/itaja-laravel`](https://packagist.org/packages/itaja/itaja-laravel) |

Using a coding agent? Point it at the skills: it reads your repository, picks the right package for your language, and checks every step in sandbox before going live.
