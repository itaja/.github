# Getting help

| You need | Go to |
|---|---|
| How Itaja works, guides, go-live checklist | [docs.getitaja.com](https://docs.getitaja.com) |
| Every route, request and response | [API reference](https://api.getitaja.com/api/references) |
| A coding agent to integrate Itaja | [itaja/skills](https://github.com/itaja/skills) |
| An SDK bug or missing feature | an issue in [itaja/itaja-sdks](https://github.com/itaja/itaja-sdks/issues) |
| A wrong or outdated agent skill | an issue in [itaja/skills](https://github.com/itaja/skills/issues) |
| Your account, a payment, a payout | your dashboard, or [hello@getitaja.com](mailto:hello@getitaja.com) |
| A security issue | [SECURITY.md](SECURITY.md) — never a public issue |

Never paste an API key, a webhook secret or customer data into an issue.
