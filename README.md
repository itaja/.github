# itaja/.github

Organisation-wide defaults for [Itaja](https://getitaja.com)'s GitHub repositories.

| File | Role |
|---|---|
| [`profile/README.md`](profile/README.md) | The page shown on [github.com/itaja](https://github.com/itaja) |
| [`SECURITY.md`](SECURITY.md) | How to report a vulnerability |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How to contribute, including conduct |
| [`SUPPORT.md`](SUPPORT.md) | Where to get help |
| [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE) | Bug and feature forms |
| [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) | Default pull request body |

A repository's own file of the same name takes precedence over these defaults.
